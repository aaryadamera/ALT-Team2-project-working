# CreditTrust AI — Explainable Loan Default Prediction

A real, running full-stack implementation of the project: a Python/FastAPI
backend that trains and serves an ensemble of 5 ML models, explains every
prediction with SHAP + LIME, logs every decision to a SQLite database, and
a frontend that talks to that backend live — matching the architecture
described in the Review-2 report (FastAPI + uvicorn backend, single-page
HTML/CSS/JS + Chart.js frontend).

See **LOGIC_WALKTHROUGH.md** for a faculty-facing guide to exactly where
each pipeline stage lives in the code and what to show during a demo.

## Project layout

```
credittrust-ai/
├── backend/
│   ├── app/
│   │   ├── main.py          FastAPI app — all /api routes, serves the frontend
│   │   ├── inference.py     Loads the promoted model, runs predict + LIME + DB log
│   │   ├── database.py      SQLite: schema, insert, and query for the audit trail
│   │   ├── schemas.py       Pydantic request/response models
│   │   └── ml/
│   │       ├── data.py         Loads the real dataset, or generates a schema-matched
│   │       │                   synthetic stand-in (no internet needed to run the demo)
│   │       ├── preprocess.py   Impute / cap-outliers / scale — shared by training AND
│   │       │                   live predictions, so they can never drift apart
│   │       ├── train.py        Trains all 5 models, evaluates, promotes the best one,
│   │       │                   computes global SHAP — run this once before starting the API
│   │       └── explain.py      SHAP (global) + LIME (per-prediction) explainers
│   ├── models/               Generated by train.py: trained model files + metrics.json
│   ├── data/                 Drop a real Kaggle CSV here (see below) — optional
│   ├── requirements.txt
│   └── credittrust.db        Generated on first run — the prediction audit log
└── frontend/
    └── index.html            3 tabs: Overview, Explainability, Try a Prediction
```

## Run it

```bash
cd backend
python -m venv venv && source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

python -m app.ml.train          # one-time: trains all 5 models, ~1-2 min
uvicorn app.main:app --reload   # starts the API + serves the frontend
```

Open **http://localhost:8000** — that's the whole app, one process.

Re-run `python -m app.ml.train` any time you want to retrain (e.g. after
dropping in the real dataset, below).

## Using the real dataset instead of the synthetic one

This environment doesn't have internet access, so the bundled generator
(`app/ml/data.py`) creates a **synthetic dataset with the identical schema**
(same 10 feature names, ~150,000 rows, a similarly-shaped ~7% default rate,
and the same missing-value / outlier issues) so the full pipeline runs
end-to-end out of the box.

To train on the real data instead:
1. Download **"Give Me Some Credit"** from Kaggle.
2. Save the training file as `backend/data/cs-training.csv`, keeping the
   original column names.
3. Run `python -m app.ml.train` again — `data.py` automatically detects and
   uses the real file. Nothing else changes.

## What's actually real here

- **Training**: 5 real scikit-learn/XGBoost models fit on real preprocessed
  data with a real stratified train/test split — not mocked.
- **Best-model selection**: genuinely picks the highest ROC-AUC model each
  time you retrain; it isn't hardcoded to XGBoost.
- **SHAP / LIME**: real explainers against the real trained model (with a
  documented, clearly-labelled fallback in `explain.py` if those two
  packages aren't installed, so the app still runs while you set up your
  environment).
- **Database**: every prediction the API serves is written to
  `credittrust.db` via `app/database.py` — open it with any SQLite browser,
  or call `GET /api/predictions/recent`, to see the audit trail live.

## API reference

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/health` | Liveness + which model is currently promoted |
| GET | `/api/leaderboard` | All 5 models' accuracy/precision/recall/F1/ROC-AUC |
| GET | `/api/shap/global` | Global SHAP feature importance for the promoted model |
| POST | `/api/predict` | Score one applicant; returns probability, risk label, LIME factors, plain-language explanation; logs to the DB |
| GET | `/api/predictions/recent` | Recent predictions from the SQLite audit log |

Interactive API docs (auto-generated by FastAPI) are at
**http://localhost:8000/docs** once the server is running — useful for
showing the raw request/response contract to faculty without touching the
frontend at all.
